# PC Logo — No Root

A minimal Android overlay app for a movable PC-style floating logo and a visual-only gaming HUD.

## Important limitations
- It does not root the phone.
- It does not modify Free Fire, inject input, automate gameplay, or change the server-side player/device identity.
- The WASD / mouse panel is visual only. Real keyboard/mouse support depends on the game and external hardware.
- Android requires the user to grant **Display over other apps** permission.

## Build
Push this folder's contents to the root of a GitHub repository. GitHub Actions runs the workflow in `.github/workflows/build.yml`.
Download `app-debug.apk` from the successful workflow run's Artifacts section.
